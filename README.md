## CLI Reflection

Using Git through the Terminal feels different from using GitHub Desktop because I have to type each command myself. GitHub Desktop is easier to understand visually, while the Terminal gives me more control over each step. I learned how to check changes with `git status`, save changes with `git commit`, and upload them with `git push`. I am still getting used to the commands, but practicing them helps me understand how Git works behind the scenes.
